# Repositório - Resolução de Problemas II 

Este repositório reúne notebooks desenvolvidos no Google Colab para experimentos de aprendizado de máquina.

## Objetivo

Investigar relações entre indicadores socioespaciais e ambientais por meio de modelos de árvores de decisão, utilizando dados dos distritos do município de São Paulo.

## Metodologia

Os experimentos utilizam algoritmos de árvores de decisão, incluindo CART, para analisar diferentes configurações de variáveis explicativas e variáveis-alvo.

A avaliação dos modelos considera métricas como:

- R² (coeficiente de determinação)
- MAE (erro absoluto médio)
- RMSE (raiz do erro quadrático médio)

## Tecnologias

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Organização

Os notebooks contêm as etapas de preparação dos dados, treinamento, validação e análise dos resultados dos modelos.
